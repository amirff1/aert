# تصاویر اسلایدها (استخراج‌شده از خود فایل pptx)

**۳۴ تصویر** از اسلایدهایی که تصویر جاسازی‌شده داشتند، با اسکریپت
`voice-notes/extract_slide_imgs.py` بیرون کشیده و برای حجم کمتر به JPEG
(حداکثر بُعد ۱۴۰۰ پیکسل، کیفیت ۸۵) تبدیل شده‌اند.

| ویژگی | مقدار |
|---|---|
| تعداد | ۳۴ تصویر |
| حجم کل | ۲٫۷ مگابایت |
| نام‌گذاری | `s<شمارهٔ اسلاید>_<نام اصلی در pptx>.jpg` |
| منبع | `ppt/media/` داخل «دکتر زادکمالی.pptx» |
| جای استفاده | بخش‌های مربوطه در `joze-kamel.md` + پیوست الف-۲ (گالری اسلایدهای ۳۷–۶۶) |

> است؛ در استخراج فقط یک بار ذخیره می‌شود و در هر دو بخش جزوه به همان فایل ارجاع داده شده است.

## بازتولید

```bash
python3 voice-notes/extract_slide_imgs.py "/path/to/دکتر زادکمالی.pptx" \
    --out work/zadkamali/slide_imgs --min-kb 40 --max-px 1400 --jpeg-quality 85
```
