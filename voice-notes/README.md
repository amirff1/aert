# 🎧 voice-notes — شنیدن صدا و ساختن جزوه

این پوشه ابزارهایی است که **صدای ضبط‌شده (و صدای داخل پاورپوینت) را به متن تبدیل می‌کند**
و از ترکیب «متن اسلایدها + متن صدا» یک **جزوهٔ درس‌نامه‌ای** می‌سازد — کاملاً آفلاین،
بدون نیاز به هیچ سرویس ابری.

```
┌──────────┐    ┌──────────────┐    ┌───────────────┐    ┌───────────┐
│ mp3/mp4  │ →  │ ffmpeg → wav │ →  │ موتور ASR     │ →  │ متن/srt   │
│ pptx/zip │    │ 16kHz mono   │    │ ۳ موتور       │    │ json/md   │
└──────────┘    └──────────────┘    └───────────────┘    └─────┬─────┘
                                                              ▼
                                    اسلایدها + نُت‌ها + متن صدا → «جزوه» (md + html)
```

## نصب سریع

```bash
bash voice-notes/setup.sh          # محیط پایتون + کتابخانه‌ها + دانلود مدل‌ها
```

سپس:

```bash
# ۱) پیاده‌سازی صدا
~/asr-venv/bin/python voice-notes/transcribe.py INPUT.mp4 --engine auto --out out

# ۲) از پاورپوینت تا جزوه (یک مرحله)
bash voice-notes/joze.sh my-presentation.pptx --language fa --title "جزوهٔ درس"
#   → out/slides/slides.md   (متن و نُت اسلایدها)
#   → out/*-media1.{txt,srt,json,md}  (پیاده‌سازی صداهای جاسازی‌شده)
#   → out/joze.html / out/joze.md     (جزوهٔ نهایی)
```

## سه موتور تشخیص گفتار

| موتور | مدل | زبان | مزیت | ضعف |
|---|---|---|---|---|
| `onnx` | Whisper-tiny int8 (beam-search، ۷۵MB) | چندزبانه | تمیزترین متن انگلیسی، نقطه‌گذاری خودکار | زمان‌بندی فقط در سطح پنجرهٔ ۳۰ ثانیه |
| `whisper` | whisper.cpp ggml-tiny (۷۴MB) | ۹۹ زبان (شامل فارسی) | چندزبانه + زمان‌بندی دقیق → SRT | دقت کمتر از beam-search |
| `vosk` | Vosk small-en-us (۴۱MB) | انگلیسی | سریع، سبک، زمان کلمه‌به‌کلمه | فقط انگلیسی |
| `vosk-fa` | Vosk small-fa-0.42 (۹۷MB) | **فارسی** | تشخیص واقعی فارسی، آفلاین | دقت متوسط در اصطلاحات تخصصی |

`--engine auto` خودش انتخاب می‌کند: فارسی → `vosk-fa`، انگلیسی → `onnx`.

### دربارهٔ کیفیت فارسی

برای فارسی از **Vosk فارسی** استفاده می‌کنیم (مدل `vosk-model-small-fa-0.42`) که از یک
مخزن گیت‌هاب با بلاب واقعی گرفته می‌شود. کیفیت آن روی گفتار عمومی قابل‌قبول است، ولی در
اصطلاحات تخصصی و کلمات انگلیسی (مثل نام داروها یا اصطلاحات ECG) خطا دارد. مدل‌های
دقیق‌تر فارسی (مثل «شنوا»/sherpa-onnx) روی سرورهایی میزبانی می‌شوند که از این محیط
بسته‌اند (HuggingFace، GitHub Releases).

نکته: `--denoise` (نویزگیری + نرمال‌سازی) روی صداهای ضبط‌شده در محیط پرصدا کیفیت را
به‌طور محسوس بهتر می‌کند.

## اجزای بسته

| فایل | کار |
|---|---|
| `transcribe.py` | هر فایل صوتی/ویدیویی → متن (txt / srt / json / md)؛ ورودی pptx/zip را خودش باز می‌کند |
| `pptx_extract.py` | متن اسلایدها + نُت گوینده + فهرست مدیای جاسازی‌شده → `slides.md` و `slides.json` |
| `make_joze.py` | اسلایدها + متن صدا → جزوهٔ چکیده‌دار با واژه‌های کلیدی (Markdown + HTML راست‌به‌چپ) |
| `joze.sh` | اجرای کل زنجیره با یک فرمان |
| `setup.sh` / `fetch_models.sh` | نصب محیط و دانلود مدل‌ها (شامل مدل‌های Hush/DF3) |

### ابزارهای «دقت بیشتر» (افزودهٔ بعدی)

| فایل | کار |
|---|---|
| `fa_pipeline2.py` | دو مدل فارسی + انتخاب پنجره‌ای بر اساس اطمینان |
| `fa_pipeline3.py` / `fa_pipeline4.py` | **رأی‌گیری چندجریانی (ROVER)**: ۴ و ۶ جریان مستقل با هم‌ترازی مهرِ زمانی |
| `fa_rover_report.py` | متن نهایی + معیارهای دقت (`transcript-fa-v3.*`, `accuracy-v3.json`) |
| `correct_fa.py` | تصحیح واژگان تخصصی فارسی بر پایهٔ قواعد دامنه |
| `make_evidence.py` | ساخت کارت شواهد هر قطعه (اسلاید + متن + واژه‌های مشکوک با جایگزین) |
| `rnnoise_dn.py` | نویزگیری RNNoise (رفع اشکال `denoise_wav` در pyrnnoise) |
| `hush_denoise.py` | **پورت پایتونی نویزگیر عصبی Hush/DeepFilterNet3** (ONNX Runtime) |
| `ab_denoise.py` | مقایسهٔ A/B روش‌های پیش‌پردازش |

## مدل‌ها کجا ذخیره می‌شوند؟

بیرون از مخزن گیت (پیش‌فرض `~/asr-models/`) تا مخزن سنگین نشود:

```
~/asr-models/
├── models/ggml-tiny.bin                  (۷۴MB — whisper.cpp)
├── whisper-onnx/whisper_cpu_int8_0_model.onnx (۷۵MB — ONNX beam-search)
└── vosk-en/vosk-model-small-en-us-0.15/  (۴۱MB — Vosk)
```

`fetch_models.sh` این‌ها را از منابع بازی می‌گیرد که در این محیط قابل‌دسترس‌اند
(مخازن گیت‌هاب با blob واقعی + رجیستری npm) و کاملاً قابل بازتولید است.

## گزینه‌های مفید `transcribe.py`

```
--engine auto|onnx|whisper|vosk     انتخاب موتور
--language fa|en|…                  زبان (پیش‌فرض: تشخیص خودکار)
--formats txt,srt,json,md           قالب‌های خروجی
--engine vosk-fa                     موتور فارسی
--denoise                            نویزگیری و نرمال‌سازی پیش از تشخیص
--beams 5                            عرض جست‌وجو در موتور onnx
--prompt "جملهٔ راهنما"               راهنمای متنی برای whisper (بهبود واژگان/لحن)
--threads 2                          تعداد هستهٔ CPU
--out DIR                            پوشهٔ خروجی
```

مثال برای فارسی (کیفیت نسبی، ولی با راهنما بهتر می‌شود):

```bash
~/asr-venv/bin/python voice-notes/transcribe.py lecture.mp3 \
    --engine whisper --language fa --prompt "این یک جلسهٔ درس دانشگاهی به زبان فارسی است."
```

## نکات کاربردی

* اگر صدا موسیقی پس‌زمینه دارد، دقت پایین می‌آید (نمونه‌اش در `demo/`). در آن حالت
  خروجی چند موتور را کنار هم بگذارید و به‌صورت دستی نهایی کنید.
* برای پاورپوینت، اگر روایت داخل فایل جاسازی شده باشد (`ppt/media/…`)، خودکار
  استخراج و پیاده‌سازی می‌شود؛ اگر فایل صوتی جدا فرستاده شود، همان را بدهید به `transcribe.py`.
* خروجی `joze.html` برای مطالعه/چاپ آماده است و کاملاً راست‌به‌چپ.
