# جزوهٔ درس ECG — دکتر زادکمالی

خروجی کار روی فایل «دکتر زادکمالی.pptx» (۶۶ اسلاید، ۳۱ قطعهٔ صوتی، **۳۲ دقیقه و ۷ ثانیه** روایت فارسی).

## فایل‌های این پوشه

| فایل | توضیح |
|---|---|
| **`joze.html`** | 📘 **جزوهٔ نهایی** — راست‌به‌چپ، آمادهٔ مطالعه و چاپ (این را باز کنید) |
| `joze.md` | همان جزوه به‌صورت مارک‌داون (قابل ویرایش) |
| **`transcript-fa.html`** / `transcript-fa.md` | پیاده‌سازی روایت استاد، **اسلاید به اسلاید** با زمان‌بندی |
| `slides-en.html` / `slides-en.md` | متن دقیق ۶۶ اسلاید (انگلیسی) |
| `transcript-fa.json` | دادهٔ ساخت‌یافته روایت (قطعه‌ها + زمان هر جمله) |
| `deck.json` | ساختار یکپارچه: هر اسلاید + متن + فایل صوتی + روایت |

## چطور ساخته شد؟

```
دکتر زادکمالی.pptx  (۸۳ مگابایت)
   │
   ├── استخراج متن ۶۶ اسلاید                        → slides-en.md
   ├── استخراج ۳۱ فایل صوتی (ppt/media/media*.m4a)   → ۳۲:۰۷ صدا
   ├── نویزگیری (afftdn) + نرمال‌سازی (loudnorm)
   ├── تشخیص گفتار فارسی — Vosk (vosk-model-small-fa-0.42)  → transcript-fa.md
   └── نگارش و تدوین جزوه بر پایهٔ اسلایدها + روایت   → joze.md / joze.html
```

نقشهٔ اتصال صدا به اسلاید از `ppt/slides/_rels/slideN.xml.rels` استخراج شده است؛
روایت روی اسلایدهای **۱ تا ۳۶** موجود است (۳۱ قطعه که چند اسلاید دو قطعه دارند).

## محتوای جزوه (۱۷ بخش)

۱. ECG چیست و چه کاربردهایی دارد
۲. لیدها: اندامی / دو-قطبی / تقویت‌شده / پرشی + رنگ الکترودها
۳. امواج، سگمنت‌ها و فواصل
۴. استاندارد ثبت: سرعت ۲۵ mm/s، گین ۱۰ mm/mV
۵. ریتم سینوسی و فرمول‌های محاسبهٔ ضربان قلب
۶. محور (Axis)
۷. موج P
۸. فاصلهٔ PR و بلوک AV
۹. کمپلکس QRS و توالی دپولاریزاسیون بطنی
۱۰. هایپرتروفی RVH و پیشرفت موج R
۱۱. موج Q فیزیولوژیک در برابر پاتولوژیک
۱۲. ولتاژ QRS و معیارهای LVH
۱۳. عرض QRS، بلوک شاخه‌ای و فاسیکولار
۱۴. QRS قطعه‌قطعه (Fragmented)
۱۵. قطعهٔ ST و ایسکمی
۱۶. موج T، موج U و فاصلهٔ QT
۱۷. اختلالات متابولیک و هیپرکالمی
+ واژه‌نامهٔ انگلیسی–فارسی

## ⚠️ محدودیت‌ها

* **متن اسلایدها دقیق است** (از XML خود فایل خوانده شده)؛ تعریف‌ها، اعداد و معیارهای بالینی جزوه از همین منبع‌اند.
* **متن روایت تقریبی است**: مدل فارسیِ در دسترس در این محیط، مدل «کوچک» است و روی اصطلاحات
  تخصصی انگلیسی (مثل RBBB یا fragmented QRS) خطای شنیداری دارد. برای نقل‌قول دقیق، فایل صوتی اصلی را بشنوید.
* فایل `.pptx` اصلی و فایل‌های صوتی در مخزن گیت ذخیره نشده‌اند (حجم بالا)؛ در پوشهٔ کاری باقی می‌مانند.

## بازتولید

```bash
bash voice-notes/setup.sh                       # محیط + مدل‌ها (یک‌بار)
~/asr-venv/bin/python voice-notes/pptx_extract.py  presentation.pptx --out slides
~/asr-venv/bin/python voice-notes/transcribe.py    presentation.pptx \
        --engine vosk-fa --denoise --out out    # → اسلایدها + متن صداها
~/asr-venv/bin/python voice-notes/deck_report.py  --work DIR
~/asr-venv/bin/python voice-notes/md2html.py       joze.md
```
